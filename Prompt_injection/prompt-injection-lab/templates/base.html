⚠ Indirect Prompt Injection Lab

💬 Comments 🤖 AI Chat
What is indirect prompt injection? An attacker embeds malicious instructions inside untrusted data (like a comment). When an LLM processes that data alongside legitimate queries, the hidden instructions can hijack the model's response — even though the user never typed them.
